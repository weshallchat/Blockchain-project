# Blockchain-project

- Implemented a proof-of-work blockchain system in Java using SHA-256 hashing, block chaining, and difficulty-adjustable nonce calculation to simulate secure transaction recording.

- Developed a client-server architecture over TCP sockets, enabling real-time blockchain updates and interactive features such as block validation, corruption, and repair via a command-line interface.

- Integrated RSA-based digital signatures for client verification, including secure message signing, hash-based identity generation, and public-key authentication on the server side to ensure request integrity.

- Optimized system performance with hash-per-second benchmarking, repair routines for corrupted chains, and multi-threaded server execution using a cached thread pool to support concurrent client sessions.
